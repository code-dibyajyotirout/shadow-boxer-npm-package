# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability or privacy concern within `shadow-boxer`, please report it via private security advisory on GitHub or email the maintainers directly.

Please do not open public issues regarding undisclosed vulnerabilities. We will respond promptly, investigate the issue, and prepare an update.
